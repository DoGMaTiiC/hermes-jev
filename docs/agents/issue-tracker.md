# Issue tracker

**Tracker**: GitHub Issues on `DoGMaTiiC/hermes-jev-skill-router` — use the `gh` CLI, always with `-R DoGMaTiiC/hermes-jev-skill-router`.

**PRs as a request surface**: off.

## How the engineering skills use this

- `/to-spec` publishes the synthesized spec as a parent issue.
- `/to-tickets` publishes one issue per ticket, blockers first; each ticket's `Blocked by` section
  names the blocking issue numbers.
- `/triage` moves issues through the label state machine in `triage-labels.md`.
