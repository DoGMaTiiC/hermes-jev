# hermes-jev-skill-router — agent notes

Hermes Agent plugin: names the one skill from the live roster that fits the turn, before the
model call, via TypeSafe Jev on the Vercel AI Gateway. Fail-open, opt-in, stdlib only.

## Agent skills

### Issue tracker

GitHub Issues on this repo (`gh issue`). See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical five, default names. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context (`CONTEXT.md` + `docs/adr/`). See `docs/agents/domain.md`.
